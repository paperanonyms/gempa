# GeMPA project page

Static site for the GeMPA paper. Served by GitHub Pages from the repository root.

```
index.html      the page
figs/           result figures (PNG)
.nojekyll       disables Jekyll so files/folders starting with _ are served
```

To publish: push to `main`, then Settings -> Pages -> Source: "Deploy from a branch",
Branch: `main`, folder `/ (root)`.
